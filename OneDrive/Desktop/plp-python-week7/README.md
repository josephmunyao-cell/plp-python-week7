# PLP Python Week 7 Assignment

## Description of Files
- **my_notes.py**: A Python script that writes, appends, reads, and counts lines in a text file.
- **my_notes.txt**: The text file generated by `my_notes.py`.
- **report_builder.py**: A Python script that reads CSV data, calculates pass/fail statistics, handles missing files safely, and writes a report.
- **hubs.csv**: The source CSV dataset containing learner scores.
- **report.txt**: The generated summary report file.

## Reflection Question
**What would happen if you changed "a" to "w" in Question 1?**
If you changed `"a"` (append mode) to `"w"` (write mode) when adding the fourth note, Python would open the file by overwriting all existing contents. As a result, the first three notes ("Python is fun", "Files are useful", and "Week 7 is going well") would be permanently erased, leaving only "I added this later" in `my_notes.txt`, and the total line count would drop from 4 to 1.
