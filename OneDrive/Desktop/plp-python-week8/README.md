# PLP Python Week 8 Final Project — Personal Mini-Toolkit

Author: Joseph M. Kiio

## Description
This project is a modular, menu-driven Python mini-toolkit designed to aggregate core programming concepts including loops, conditionals, mutable lists, user input handling, error checking (`try-except`), and friendly f-string formatting.

## Included Tools
1. **Interactive Calculator**: Computes standard math operations (+, -, *, /) with error catching for division by zero.
2. **Dynamic To-Do List**: Manages an active task list with options to view, add, and remove items dynamically.
3. **Number Guessing Game**: An interactive loop-driven game challenging the user to guess a randomized secret number.

## How to Run
1. Ensure you have Python installed on your system.
2. Clone or download this repository.
3. Open your terminal in the repository folder and run:
   ```bash
   py toolkit.py
